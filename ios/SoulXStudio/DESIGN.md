# SoulX Studio design

Native iPhone operation surface. A large portrait stage leads into two bundled avatar cards, audio selection and one primary action. Indian is selected initially; Asian is the other confirmed repository avatar. Cards show a source thumbnail, label and selected checkmark with an orange outline. Charcoal surfaces and a restrained orange tint support quiet viewing of the generated face. System navigation, sheets, buttons, typography, SF Symbols and Dynamic Type preserve native behavior.

Use semantic system backgrounds and text. Orange is reserved for interactive emphasis. The portrait stage has a 16-point continuous radius. Horizontal page padding is 20 points; control groups use 12-point spacing and at least 44-point targets. A monospaced digit style is reserved for measured FPS, frame counts and elapsed time. Transitions use native navigation and opacity; no synthetic generated frames or decorative motion.

Empty, initializing, ready, generating, buffering, completed and failed states are explicit. Models and advanced compute settings live in a native settings sheet. The large title and frame viewer remain legible at accessibility text sizes in the vertical scroll layout.
